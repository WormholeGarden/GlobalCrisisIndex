Plain-English Explainer

How one crisis score
gets built from 40 live feeds

This page walks through how the Top-Story API turns raw information from 40+ sources into a single 1–99 score for 179 countries, refreshed every five minutes.

Think of it like a hospital triage system. Ambulances bring in patients (data feeds). Nurses assess each one (evidence rules). Doctors combine that with the patient's medical history (baseline). The final triage score decides who gets seen first — but it never replaces the full medical chart.
01
Collect

40+ sources send in their reports

Imagine 40+ different newsrooms, each watching a different type of event. They all send updates to the same inbox. If one source is late or fails, the others still get through — nothing waits for a single slow reporter.

02
Weigh

Each report gets a trust score

54 rules turn incoming reports into points. Each rule knows how much to trust its source — a confirmed WHO outbreak counts far more than a single stale wildfire ping.

How it works in plain terms
✅ Trustworthy source + strong signal → high points
⚠️ Weak source + weak signal → few points
📊 More sources agree → higher confidence in the score

Neighbors

Crises leak across borders — but gently

If a neighboring country is in crisis, it nudges your score up a little. But the effect is capped and dampened — especially for countries already scoring high — so spillover never dominates the final number.

06
Urgency

A separate layer decides how urgent the headline is

This layer doesn't change the score itself — it only decides how loud the alert should be right now. Fresh signals count more; older ones fade away.

07
Sort

A hidden "effective" score decides the order

For ranking purposes only — never shown as the real score — the system adjusts for population size and gives credit when refugee situations resolve. Then it sorts by urgency first, size second.

Think of it like a leaderboard tiebreaker
👥 Bigger population → the crisis affects more people, so it ranks slightly higher.
🕊️ Resolved refugee situations → a small credit that lowers the ranking pressure.
📋 The displayed score never changes — only the sort order does.
